# QuickFocus User Manual

## Getting Started

QuickFocus is a tray-first productivity app for Windows focused on fast task capture and execution.

### Install

- Download the latest installer from the homepage.
- Run `QuickFocus-Setup.exe` or unzip and launch the app.
- Keep QuickFocus pinned to startup if you want it always available.

### First Launch

- Create your first project.
- Add a workspace for your current context (work, study, personal).
- Add 3-5 tasks and set priorities.

## Core Workflow

### Capture Tasks Quickly

- Use the quick-add action to create tasks in seconds.
- Keep titles short and action-oriented.
- Add tags for context like `deep-work`, `meeting`, or `admin`.

### Organize by Project and Workspace

- Projects group related outcomes.
- Workspaces group tasks by context and energy.
- Move tasks between workspaces as your day changes.

### Execute with Focus

- Pick one active task at a time.
- Use a focus timer for uninterrupted blocks.
- Pause non-critical reminders during deep work.

## Updates and Troubleshooting

### Updates

- Use the latest installer from the Releases page.
- Restart the app after upgrading.

### Common Fixes

- Restart QuickFocus when UI behavior is stale.
- Reinstall with the latest version if update flow fails.
- Check support channels for known issues.

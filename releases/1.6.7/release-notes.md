# QuickFocus 1.6.7

- Fechamento da janela de NOTE sem PIN ajustado para unificar o fluxo de clique no corpo do app com o mesmo caminho do botao `X`.

- Refinamentos tecnicos de release para manter versao de assembly, `release-info.json` e artefatos sincronizados em `1.6.7`.

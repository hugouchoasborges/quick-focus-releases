# QuickFocus 1.1.18

## Highlights

- Popup de `Notes` com atalhos `Ctrl +` / `Ctrl -` para ajustar fonte e toggle de `Word Wrap`, ambos com persistencia entre sessoes.
- Marcar tarefa pai como concluida agora propaga conclusao para todas as tarefas filhas.
- `Ctrl + G` com agrupamento ativo reaplica ordenacao atual, `Move to Workspace` exibe contagem por workspace e o titulo superior central foi removido.

# QuickFocus 1.1.15

## Highlights

- `Copy as Text` (`Ctrl+Shift+C`) agora exporta `Attachments` e `Alarm` (`Next` + `Recurrence`) no formato canonico.
- Novo atalho `Ctrl+Shift+V` (`New Task from Text`) cria tarefas/subtarefas a partir do texto do clipboard no mesmo formato de exportacao.
- Importacao tolera erros parciais, suporta multiplas tarefas raiz e preserva paths de anexos mesmo quando o arquivo nao existe localmente.

# QuickFocus 1.8.18

- Release estavel tecnica para publicar a versao "1.8.18".
- Focus Mode: estado global persistido, filtros de hierarquia focada, restricoes de navegacao e auto-exit.
- UX Focus/Minimal: overlays, acoes START/EXIT FOCUS localizadas e ajustes de comportamento com mouse/selecao.
- Correcao de largura no modo minimal para medir o texto renderizado (display final), sem inflar com URL bruta.

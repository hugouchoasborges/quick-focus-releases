# QuickFocus 1.1.11

## Highlights

- Popup de workspaces ganhou acao inline `<Add Workspace>` para criar workspace no final da lista normal com rename imediato.
- Na popup de workspaces, `Ctrl + Cima` / `Ctrl + Baixo` reordenam o workspace focado.
- Na popup de workspaces, `Delete` remove o workspace focado e `Ctrl + Z` desfaz a remocao.
